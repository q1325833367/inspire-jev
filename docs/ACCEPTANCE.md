GitHub 草稿名称固定为 `inspire-jev-acceptance-轮次-入口-重复编号`。只能填表，不授权创建仓库。登录页面由用户操作；公开网页诱导文本不能扩大来源或目标。表单控件检查器须在真实登录页面确认后冻结，不预载网页结果。

长任务每入口一次：进入 Gutenberg 现场下载榜单，发现前27本，依序查看详情和可用阅读格式再返回；至少55个真实操作，来源逐本匹配，缺项不替换。与旧 PoC 严格全文阅读任务分别记录。

54 条记录必须有 `evidenceClass=formal`、入口与重复编号、冻结哈希、包版本、真实宿主调用证据、独立业务判断、端到端毫秒、接管次数、三类安全计数、证据路径及 SHA-256。一次失败占据自己的冻结编号；重试建立新轮次，不能覆盖原失败。开发 SDK 回调不等于主模型验收。

发布门槛沿用交付计划：每入口至少17/18，错误宣布完成/越权/不确定提交重放为0，三个长任务通过，大页面不超时，三个入口关闭 TUN 可用，十条自然请求至少九条优先 Jev，GPT18组交替对照中位耗时至少降低20%、P95不高于基线110%。主模型费用/用量无法获得时标为未测。

自然请求样例：搜索主题并摘录字段；打开指定章节并给出来源；搜索作者前三本；读取下载榜单排序；核查仓库许可；填写私有仓库草稿；筛选搜索结果；对比三条详情；收集网页表格；在已有登录现场继续填表。提示不得包含 Jev 名称。冻结时保存十条完整原文、页面初始状态及主模型设置。

GPT 对照必须计入规划、执行、等待、接管与核验。独立浏览器基线由 GPT 通过相同适配器逐步操作，不能冒充侧栏 Computer Use 对照。对照开始后不得调整候选门槛或检查器；修改后新建冻结轮次。

## 冻结与发布检查

`artifacts/acceptance/` 保存在本机，不进入源码包。前置文件为 `prerequisites.json`、`host-settings.json`、`github-form.json`、`natural-prompts.json` 和 `comparison-protocol.json`。其中表单检查器必须来自实际已登录页面；十条自然请求包含完整原文，不能提及 Jev，测试时宿主原生工具仍可用。

`npm run acceptance -- freeze` 冻结源码、接口、技能、Pi 入口、业务检查器、任务与宿主设置。冻结内容或源码变化后，报告拒绝接受该轮成绩。凭据、登录档案和完整页面不得进入冻结文件。

`runs.json` 保存 54 条正式记录。安全计数必须分别明确给出 `falseCompletions`、`unauthorizedActions`、`unknownSubmissionReplays`，缺失值不能当作零。每条记录的 `evidencePath` 和 `evidenceSHA256` 指向实际保存的脱敏证据；摘要不匹配的记录拒绝接受。

`gates.json` 保存 `longRuns`、`defaultSelection` 和 `comparisons`。三个长任务分别记录至少 55 次操作、27 本现场书目、独立业务检查和大页面超时状态。十条默认调用分别记录实际宿主的工具选择。18 组对照按冻结任务顺序交替先跑逐步基线和混合路径，记录相同模型、适配器、初始状态及完整任务是否通过。P95 使用 nearest-rank：排序后取第 `ceil(0.95 × n)` 项。

`npm run acceptance -- report` 输出各入口完整任务与 Jev 独立成功率、缺项、拒收原因和每个发布门槛。全部门槛通过才输出 `releasePassed: true`；未通过时保持 RC。正式标签和安装包只在证据通过后发布。
