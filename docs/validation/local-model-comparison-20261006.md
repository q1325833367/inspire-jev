# 云端与本地决策模型：真实网页开发对照

日期：2026-10-06。对应本地功能版本：1.1.0-rc.1。本地选项保持实验能力，云端 Jev 继续作为默认。

## 结论与实测

本轮使用同一组公开网站、同一浏览器适配器和完成要求。本机 **OpenJev／SemIf 可以完成这组单阶段任务，但决策中位耗时约为云端的 5.44 倍**。Kev-0.5B 速度较快，业务完成率不足；Laya 当前批量路径未得到有效响应，不能据此计算其有效准确率。

|模型与实际后端|固定观测选对操作及目标|决策请求中位耗时|完整单阶段流程通过|
|---|---:|---:|---:|
|TypeSafe Jev 1.13.0|9/9|0.797 秒|9/9|
|OpenJev／SemIf，Qwen3.5-4B，MLX，加本项目桥接|6/9|4.335 秒|9/9|
|Kev-0.5B，官方 torch／MPS／fp32|3/9|0.310 秒，包含错误选择|0/9|
|Laya multilingual，官方 torch／MPS|无有效响应；9 次 HTTP 422|不作有效决策速度比较|0/9|

完整流程全部包含实际导航、采集和完成条件核验；成功运行各执行一次真实交互。未发生主 Agent 接管或人工代做。固定观测回放与完整流程是两个不同检查：回放直接输入目标；完整流程还提供实际未通过的完成条件。SemIf 的三次回放错误均是在 Gutenberg 首页错误选择 `DONE`；完整流程在收到未通过的 URL／元素要求后选择了正确入口。这不能证明它在任意任务中不会错误选择 `DONE`。

失败返回接管：Kev 完整流程的 `DONE` 被业务核验拒绝，未被记录为已完成；Laya 接口失败未发起浏览器动作。不能将错误响应的快速返回当作速度优势。

## 方法与范围

- 设备：Mac Studio、Apple M3 Ultra、256 GB 内存，macOS ARM64。TUN 关闭；网页和云端显式使用代理，本地决策直连。
- 三个真实网站：Gutenberg 首页进入下载榜单并采集前三本；Books to Scrape 进入 Travel 分类并采集前三本名称和价格；Wikipedia 通过目录进入 Alan Turing 的 Death 章节并读取首段。
- 三个固定观测，各模型重复三次，共 36 次决策请求；三个流程各模型重复三次，共 36 次任务运行。先冻结输入哈希，再轮转模型顺序；同组回放状态和候选完全相同。
- 每批最多 36 个候选、1,200 字符摘要，保留未覆盖游标。完整流程使用相同窗口；核验与采集独立读取实际页面。
- 任务预算：90 秒、40 次动作、45 秒片段。模型请求默认 25 秒超时。
- 决策计时使用单调时钟，包含 HTTP、推理、响应读取和格式检查；服务已加载，不包含权重下载或冷启动。
- 完整流程耗时保留在机器记录中。期间另有一次真实 stdio MCP 冒烟与流程重叠，因此本报告仅用无重叠的固定观测阶段比较决策速度，不发布完整任务提速结论。
- 这是 SDK／执行核心开发对照，不是 GPT、Pi、CLI 主模型端到端对照；未测主模型用量与费用。每个流程仅一次交互，不能代替长任务、复杂表单或全部网站验收。三个不同任务重复三次，也不等于九个独立场景。

SemIf 原生每问题最多 16 个选项。本项目桥接保留全部候选，分组评分后以组概率乘条件概率形成完整分布；并只对评分器读取的位置执行原生词表投影。原生与优化投影的小输入校验中，选项概率最大差异为 0、选择一致。该结果只证明本次一致性检查，不是全部输入的证明。报告成绩属于 **SemIf 加本项目桥接**，不能冒充上游原生服务成绩。

SemIf 初次本机加载约 22.7 秒，随后缓存加载约 6.9–7.0 秒；首次权重下载另计。其模型权重不是 TypeSafe 官方 Jev 权重。

## 保留的失败与诊断

扩大到原来的 120 候选、5,000 字符窗口时，Laya 曾返回 HTTP 413／422，Kev 回放选择错误，SemIf 大批次请求超过 25 秒。其原生批量路径诊断采样峰值占用约 68.8 GB。仅减少词表投影未解决这组超时；缩小通用观测批次后得到本轮可用结果。较小批次会增加大页面发现次数，尚需长任务验证。

Laya 在单问题诊断中返回有效分布，但多问题批量请求返回非有限数值错误；改变 MPS 自动混合精度设置、使用 transformers 4.57.6 后仍未完成这组批量流程。根因尚未确认，不将接口故障归结为模型准确率低，也不隐式改成逐问题串行来冒充并行成绩。

历史轮次 `r01` 完整保留；`r03/r04` 为中止的诊断轮次，所有已发出的请求均保留；`r02` 因服务尚未就绪在预检退出，未产生测试成绩。后续成功没有替换早期失败。
