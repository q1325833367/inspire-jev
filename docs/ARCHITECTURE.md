# 架构

主 Agent 组织原始目标、自然业务阶段和独立完成条件；共享 JavaScript 核心执行阶段。明确值和唯一目标直接执行，Jev 在新鲜候选中选择动作，DeepSeek 按需生成新文字。每次检查实际效果，失败返回原现场供主 Agent 接管，续跑重新观测。

`Agent` 负责会话、请求幂等、检查点和取消；`BrowserAdapter` 负责有限分批观测、目标局部校验及执行。模型不能生成代码或定位器。来源、权限和完成要求由主 Agent 与宿主约束，网页内容不能扩大权限。

GPT 插件、Pi 扩展、stdio MCP 注册同一组工具，复用核心，各自保存会话和登录档案。Pi 调度与主模型保持原配置。GPT 的侧栏与独立浏览器能力分开记录。

观测报告覆盖、截断、滚动区域和控件能力；单批扫描、页面计算和返回候选均有预算。局部缺失先继续发现。语义填写、复选框与原生选择避免重复盲点；普通可核验操作不使用统一置信度硬门槛。

写入锁基于真实浏览器和标签页身份，跨句柄互斥；崩溃恢复核对进程身份。动作依次持久化 prepared、dispatching、acknowledged，效果未知时检查原现场，不直接重放提交。取消后不发新动作，已发动作保留真实结果。

任务默认总预算 90 秒、40 次动作；每片段最多 45 秒。长任务显式给出 15 分钟、200 次动作，预算跨片段累计。`verified` 必须有独立条件和逐阶段证据，主 Agent 最终核对原始要求覆盖。

工具参数与恢复协议见 [API](API.md)；实测标准见 [验收协议](ACCEPTANCE.md)。
